# Mobile-App-Development-Portfolio
# 📱 Android Portfolio Assessment

This repository contains my **individual Android Development portfolio**, organized into four codelab units. Each unit documents my learning progress and practical experience with **Kotlin, Android Studio, user interface development, Material Design, app architecture, navigation, and responsive design**.

Throughout the portfolio, I have included **achievement badges, Kotlin practice exercises, implementation examples, and personal reflections** to demonstrate the knowledge and skills I developed while completing each unit.

---

## 📚 Units Overview

### Unit 1: Your First Android App

* **Duration:** 10 hours
* **Pathways:** Introduction to Kotlin, Setup Android Studio, Build a Basic Layout
* **Focus:** Learning the fundamentals of Kotlin programming, setting up the Android Studio development environment, and creating a simple Android user interface using text and images.
* **Deliverables:** Achievement badge, Kotlin practice code, and reflection notes.

#### Reflection

In Unit 1, I was introduced to the fundamentals of Android application development. I learned how to write simple Kotlin programs, configure Android Studio, and understand the basic structure of an Android project. I also practiced creating simple layouts containing text and images and learned how to run an application using an emulator or physical Android device.

One of the main challenges I faced was setting up Android Studio and configuring the emulator correctly. Understanding the structure of Android layouts was also unfamiliar at first. However, completing the exercises helped me become more comfortable with the Android development environment and gave me a strong foundation for the following units.

---

### Unit 2: Building App UI

* **Duration:** 21 hours
* **Pathways:** Kotlin Fundamentals, Add a Button to an App, Interacting with UI and State
* **Focus:** Strengthening Kotlin programming skills and learning how Android applications respond to user interaction and changes in application state.
* **Deliverables:** Achievement badge, Kotlin fundamentals exercises, button interaction simulation, tip calculator logic, and reflection notes.

#### Reflection

Unit 2 helped me strengthen my understanding of Kotlin by introducing concepts such as **conditionals, classes, lambda expressions, functions, and function types**. These concepts showed me how programming logic can be connected to application behavior.

I also learned how applications respond to user actions, particularly button clicks, and how values displayed on the screen can change based on user input. The tip calculator activity helped me understand the relationship between application logic, user input, and UI state.

The most challenging part of this unit was understanding lambda expressions and function types because they were different from the programming concepts I had previously used. With additional practice, I became more confident in using them and understanding how they support event-driven Android applications.

---

### Unit 3: Display Lists and Use Material Design

* **Duration:** 15 hours
* **Pathways:** More Kotlin Fundamentals, Build a Scrollable List, Build Beautiful Apps
* **Focus:** Working with Kotlin data structures, displaying collections of information, handling user interactions, and applying Material Design principles.
* **Deliverables:** Achievement badge, Kotlin data class exercises, list simulations, Material Design practice, and reflection notes.

#### Reflection

In Unit 3, I expanded my Kotlin knowledge by working with **data classes, collections, functions, and lists**. I learned how applications can organize multiple pieces of information and display them efficiently through scrollable interfaces.

I also explored how click listeners allow users to interact with items displayed in an application. Another important part of this unit was learning about **Material Design**, including the use of colors, typography, shapes, spacing, and accessibility to create interfaces that are both visually attractive and easy to use.

One challenge was understanding how Kotlin collections are connected to UI components in a real Android application. Applying Material Design concepts through simplified Kotlin exercises also required me to think about both functionality and visual design. Overall, this unit improved my understanding of how data and UI design work together.

---

### Unit 4: Navigation and App Architecture

* **Duration:** 28 hours
* **Pathways:** Architecture Components, Navigation in Jetpack Compose, Adapt for Different Screen Sizes
* **Focus:** Understanding Android application architecture, state management, screen navigation, lifecycle concepts, and responsive user interface design.
* **Deliverables:** Achievement badge, architecture simulation, navigation exercises, responsive UI simulation, and reflection notes.

#### Reflection

Unit 4 introduced me to more advanced Android development concepts, particularly **app architecture, ViewModels, StateFlow, navigation, and responsive design**. I learned why separating application logic from the user interface is important for creating applications that are easier to maintain and expand.

I also learned how navigation allows users to move between different screens while maintaining appropriate application state. Studying activities and their lifecycles helped me understand how Android manages screens when an application is opened, paused, resumed, or closed.

Another important concept was adaptive and responsive design. I learned that Android applications should be designed to work effectively across different screen sizes, including smartphones, tablets, and larger displays.

StateFlow and **Unidirectional Data Flow (UDF)** were among the most challenging concepts because they required me to understand how application state moves between different components. However, completing the unit gave me a clearer understanding of how modern Android applications are structured.
